## ✨ Sobre o jogo

E se cada conta fosse uma pincelada?

No **Pixel Colors Math**, pintar uma imagem vai além de escolher uma cor. Cada cor está associada a um número, e o caminho para descobri-la passa pela resolução de operações matemáticas.

É uma maneira leve e divertida de exercitar o raciocínio enquanto uma imagem em pixel art ganha forma, quadradinho por quadradinho.

## 🎮 Como jogar

1. **Observe a operação matemática** apresentada no jogo.
2. **Resolva a conta** para descobrir seu resultado.
3. **Associe o resultado à cor** indicada pela legenda.
4. **Pinte os pixels correspondentes** e veja a ilustração aparecer!
5. **Complete a imagem** e aproveite o resultado do seu trabalho. 🌈

> 💡 **Exemplo:** se `3 + 4 = 7` e o número **7** representa a cor azul, os pixels associados a essa resposta devem ser pintados de azul.

## 📱 Um jogo PWA

O **Pixel Math** é desenvolvido como uma **Progressive Web App (PWA)**, combinando a praticidade de um jogo acessado pelo navegador com uma experiência pensada para dispositivos móveis.

A proposta é simples: abrir, calcular e colorir, sem complicações!
